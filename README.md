# LanguageBridge

AI-powered multilingual language translation platform built using Python Flask and Google Translate API.

## Features

* Translate text between multiple languages
* Automatic language detection
* Copy translated text
* Text-to-Speech support
* Dark Mode
* Translation History
* Character Counter
* Language Swap Feature
* Responsive User Interface

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
* Googletrans API

## Installation

1. Clone the repository

git clone https://github.com/anitha24-5L9/LanguageBridge.git

2. Install dependencies

pip install -r requirements.txt

3. Run the application

python main.py

4. Open browser

http://127.0.0.1:5000
